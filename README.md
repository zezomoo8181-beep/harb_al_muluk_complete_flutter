# حرب الملوك — مشروع Flutter متكامل للتجربة

## محتويات المشروع
- `lib/main.dart`: واجهة اللعبة والمنطق المحلي.
- `lib/game_state.dart`: الموارد، الحفظ، الإنتاج عند العودة، المباني والجيش.
- `lib/theme.dart`: الثيم الداكن والذهبي.
- `assets/images/kingdom_icon.png`: صورة هوية بصرية للمملكة.
- `.github/workflows/main.yml`: سير عمل GitHub Actions لبناء APK ورفع الناتج كـ Artifact.
- `pubspec.yaml`: الاعتمادات وموارد Flutter.

## الميزات الموجودة
- واجهة عربية مناسبة للموبايل.
- موارد خشب وحجر وحديد وطعام وذهب.
- مبنى قيادة ومنشرة ومحجر ومنجم ومزرعة وثكنة وسور.
- تطوير بمصاريف ومؤقت ثوانٍ.
- إنتاج موارد عند العودة إلى اللعبة (بحد أقصى 8 ساعات).
- تدريب مشاة ورماة وفرسان.
- معركة تدريبية محلية بنتائج وغنائم.
- خريطة تجريبية مرسومة داخل Flutter.
- مهام يومية ومكافآت.
- حفظ تلقائي محلي وإعادة بداية مع تأكيد.

## بناء APK في Klencod IDE
1. استورد هذا ZIP كمشروع Flutter.
2. نفّذ Pub Get / Get dependencies.
3. اضغط Build APK.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المشروع إلى مستودع GitHub.
2. افتح Actions.
3. اختر `Build Harb Al Muluk APK`.
4. اضغط Run workflow.
5. بعد النجاح افتح التشغيل ونزّل Artifact باسم `harb-al-muluk-release-apk`.

## تنبيه تقني مهم
هذه لعبة فردية قابلة للتجربة مع حفظ محلي، وليست بعد لعبة أونلاين متعددة اللاعبين. لا توجد في هذا المشروع قاعدة بيانات مشتركة أو حسابات أو تحالفات أو خادم معارك. هذه تتطلب خادم API وقاعدة بيانات ونشرًا منفصلًا، ولا يمكن اعتبارها مكتملة بمجرد بناء APK.
